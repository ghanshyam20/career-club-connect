# Career Club Connect — local starter

**Status:** Milestone 1 foundation only. No production authentication or full product modules yet. Independent fictional-data prototype, not endorsed by City of Espoo.

## Start here

1. Read `docs/START_HERE.md` and `docs/CURRENT_STATE.md`.
2. Run the prerequisite checks in `docs/SETUP_UBUNTU.md`.
3. Run the commands there in order, from this repository root.
4. Keep `docs/CURRENT_STATE.md` updated after every working session so a new chat can continue without guessing.

**Stack:** Next.js + TypeScript; Django REST Framework + Python venv; PostgreSQL via Docker Compose. No paid hosting needed.

**Important:** `docs/source/` contains the prior planning documents. Proposed decisions are not automatically approved. The four explicit owner approvals are recorded in `docs/DECISIONS.md`.
