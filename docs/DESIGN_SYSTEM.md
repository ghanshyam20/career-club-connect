# Visual design baseline (proposed, pending owner sign-off)

Nordic blue/white, clean sans-serif, mobile-first. Proposed: navy `#102B4E`, blue `#1769E0`, page `#F6F9FC`, white surfaces, border `#DCE4ED`; 4px spacing grid, 12px cards. Five mobile tabs: Home, Explore, Community, Actions, Profile. Desktop sidebar adds Coffee Buddy. No unsupported UI buttons.

Use `source/CAREER_CLUB_CONNECT_DESIGN_AUDIT.md` for full proposed tokens, states, breakpoints, accessibility and component inventory. The starter frontend is **not** a complete design implementation.
